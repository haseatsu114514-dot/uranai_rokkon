## 修正した主な問題

1. 管理者通知
   - LINEは見逃し防止に必要な要点と次の操作を表示する。
   - 管理者メールは予約者情報、希望日時、相談内容、支払方法、仮押さえ実時刻、各処理の成否、予約シートの該当行リンク、次のアクションを表示する。
   - 個人情報を必要以上にLINEへ送らず、詳細は管理者メールと予約シートに限定する。

2. 予約処理
   - 同時予約をロックし、同じ枠を二重に仮押さえしない。
   - 入力値をサーバー側でも検証する。
   - 仮予約イベントIDを保存し、同姓同名の別予約を誤って変更・削除しない。
   - 第二希望で確定した場合も、その希望帯の空き時刻へカレンダーを移動する。
   - メール、LINE、カレンダーの失敗を「システム処理結果」列へ残す。

3. お客様向け表示
   - プライバシーポリシーと同意チェックを追加した。
   - 受付確認メールの送信だけ失敗した場合、完了画面で連絡を促す。
   - ブログ一覧に不足していたH1を追加し、旧Googleフォームへの導線を現行予約フォームへ統一した。
   - 全ページのスマートフォンメニューをキーボード・読み上げ対応のボタンへ変更した。
   - 当日希望を開始3時間前まで受け付け、確定前であることをフォーム・完了画面・受付確認メールのすべてで明示した。

4. 運用・自動更新
   - ブログ更新ワークフローを依存パッケージ対応のNode.js 22へ更新し、再現可能な `npm ci` を使う。
   - 本番コードの版と秘密設定の有無を確認できる `?action=health` を追加した。
   - 管理者メールだけを安全に確認できる `testOwnerEmailPreview()` を追加した。
