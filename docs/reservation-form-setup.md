# 予約フォームをうごかす手順（かんたん版）

むずかしい作業はスクリプトが全部自動でやるので、
**実際にやることは「コピペ → ボタンを2回押す → 出てきたURLを貼る」だけ**です。

```
ステップA: Google側の準備 …… 約10分（コピペと承認だけ）
ステップB: サイトにURLを貼る …… 約5分
ステップC: LINE通知をつける …… 任意・あとまわしでOK
```

ステップAとBが終わった時点で、フォームは動きます。
（その間も予約は **メール通知＋Googleカレンダーのスマホ通知** で届くので、見逃しません）

---

## ステップA: Google側の準備（約10分）

### A-1. コードを貼り付ける

1. https://script.google.com を開く（普段使っている uranai.rokkon@gmail.com でログイン）
2. 左上の「**＋ 新しいプロジェクト**」を押す
3. 最初から書いてある `function myFunction() {...}` を全部消す
4. このリポジトリの `google-apps-script/reservation.gs` の中身を**全部コピーして貼り付ける**
5. 上の「無題のプロジェクト」をクリックして、名前を「予約受付」に変える

### A-2. setup を1回だけ実行する

1. 画面上のほうにある関数を選ぶプルダウン（「doPost」などと表示されている所）をクリック
2. 「**setup**」を選ぶ
3. その左の「**▷ 実行**」ボタンを押す
4. 「承認が必要です」と出るので：
   - 「権限を確認」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら
     「**詳細**」→「**予約受付（安全ではないページ）に移動**」→「**許可**」
     （自分で作ったスクリプトなので大丈夫です）
5. しばらく待つと、下のログに「✅ 設定完了！」と出ます

これだけで、**記録用スプレッドシートの作成・見逃し防止リマインドの設定・テストメール送信**まで全部終わっています。Gmailに「【設定完了】」のメールが届いているか確認してください。

### A-3. ウェブアプリとして公開する

1. 右上の青い「**デプロイ**」→「**新しいデプロイ**」
2. 左の歯車マーク →「**ウェブアプリ**」を選ぶ
3. 設定を2か所だけ確認：
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員** ←ここ大事！
4. 「デプロイ」を押す
5. 表示された「**ウェブアプリのURL**」（https://script.google.com/macros/s/...で始まる長いURL）をコピーしておく

---

## ステップB: サイトにURLを貼る（約5分）

`js/reserve.js` を開くと、上のほうにこう書いてあります：

```js
const RESERVE_ENDPOINT = '';
```

この `''` の間に、さっきコピーしたURLを貼ります：

```js
const RESERVE_ENDPOINT = 'https://script.google.com/macros/s/あなたのURL/exec';
```

保存して main に push（いつものデプロイ）すれば、**フォーム予約が動き始めます**🎉

> 💡 URLを貼るまでの間、サイトのフォーム欄には自動で
> 「準備中です。LINEからご予約ください」と表示されるので、
> 先にサイトだけ公開しても大丈夫です。

**動作テスト**: 自分で reserve.html から1件予約してみてください。
①自分のGmailに通知 ②カレンダーに【仮】イベント ③お客様用アドレスに自動返信、の3つが届けば完璧です。

---

## ステップC: LINE通知をつける（任意・あとまわしOK）

メール＋カレンダー通知だけでも運用できますが、「LINEが一番見る」場合は追加でどうぞ。
ここだけは LINE 側のサイトでの作業が必要です（約15分）。

> ⚠️ ネット記事でよく出てくる「LINE Notify」は2025年3月に終了しています。
> 下の「Messaging API」のやり方が現在の正解です。

1. https://developers.line.biz/console/ にログイン（普段のLINEアカウントでOK）
2. 「プロバイダー」を作成（名前は「六根清浄」など何でも）
3. 「**Messaging API**」のチャネルを新規作成
   - 名前は「予約通知」など。これは**自分専用の通知Bot**で、お客様向け公式LINEとは別物です
4. 作ったチャネルの「**Messaging API設定**」タブを開き：
   - 一番下の「**チャネルアクセストークン（長期）**」→「発行」→ コピー
   - 同じタブにある**QRコードを自分のスマホのLINEで読み取って友だち追加**（これを忘れると届きません）
5. 「**チャネル基本設定**」タブの一番下にある「**あなたのユーザーID**」（Uで始まる文字列）をコピー
6. GASに戻って、コード上部の CONFIG に貼り付ける：

```js
LINE_CHANNEL_ACCESS_TOKEN: '（4でコピーしたトークン）',
LINE_OWNER_USER_ID: '（5でコピーしたUから始まるID）',
```

7. 関数プルダウンから「**testNotify**」を選んで実行 → 自分のLINEに通知が来たら成功！
8. 最後に**デプロイの更新**：「デプロイ」→「**デプロイを管理**」→ 鉛筆マーク → バージョン「**新バージョン**」→「デプロイ」
   （これをやらないとコードの変更が反映されません。今後コードを直したときも同じです）

---

## 日々の運用（やることは2つだけ）

1. 通知が来たら、お客様へ**確定メールを返信**してお支払いをご案内する
2. スプレッドシートの「**対応状況**」列に「対応済み」と書く
   （書かないと3時間後にLINEへ「未対応の予約があります」と再通知が来ます。これが見逃し防止の保険です）

カレンダーの【仮】イベントは、確定したら正式な時間に直してください。

---

## こまったときは

| 症状 | 確認すること |
|------|--------------|
| フォームが「準備中」のまま | ステップBのURL貼り付け＆pushができているか |
| 送信するとエラーになる | A-3で「アクセスできるユーザー: 全員」になっているか |
| LINE通知が来ない | Botを友だち追加したか／testNotifyで届くか／C-8のデプロイ更新をしたか |
| お客様にメールが届かない | 迷惑メールフォルダ。Gmailの無料アカウントは1日約100通まで送信可（予約用途なら十分） |
| 記録シートはどこ？ | 「【設定完了】」メールにURLが書いてあります（Googleドライブにもあります） |
