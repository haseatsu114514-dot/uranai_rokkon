# 予約フォームをうごかす手順（かんたん版）

むずかしい作業はスクリプトが全部自動でやるので、
**実際にやることは「コピペ → ボタンを2回押す → 出てきたURLを貼る」だけ**です。

```
ステップA: Google側の準備 …… 約10分（コピペと承認だけ）
ステップB: サイトにURLを貼る …… 約5分
ステップC: LINE通知をつける …… 任意・あとまわしでOK
```

ステップAとBが終わった時点で、フォームは動きます。
（その間も予約は **メール通知＋Googleカレンダーのスマホ通知** で届くので、見逃しません）

---

## ステップA: Google側の準備（約10分）

### A-1. コードを貼り付ける

1. https://script.google.com を開く（普段使っている uranai.rokkon@gmail.com でログイン）
2. 左上の「**＋ 新しいプロジェクト**」を押す
3. 最初から書いてある `function myFunction() {...}` を全部消す
4. このリポジトリの `google-apps-script/reservation.gs` の中身を**全部コピーして貼り付ける**
5. 上の「無題のプロジェクト」をクリックして、名前を「予約受付」に変える

### A-2. setup を1回だけ実行する

1. 画面上のほうにある関数を選ぶプルダウン（「doPost」などと表示されている所）をクリック
2. 「**setup**」を選ぶ
3. その左の「**▷ 実行**」ボタンを押す
4. 「承認が必要です」と出るので：
   - 「権限を確認」→ 自分のアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら
     「**詳細**」→「**予約受付（安全ではないページ）に移動**」→「**許可**」
     （自分で作ったスクリプトなので大丈夫です）
5. しばらく待つと、下のログに「✅ 設定完了！」と出ます

これだけで、**記録用スプレッドシートの作成・見逃し防止リマインドの設定・前日リマインド／月次レポートの定期実行・テストメール送信**まで全部終わっています。Gmailに「【設定完了】」のメールが届いているか確認してください。

> 💡 ついでに確認: GASの左メニュー⚙️「プロジェクトの設定」→「タイムゾーン」が
> 「(GMT+09:00) 東京」になっているか見てください（違うと前日リマインドの時刻がずれます）。

### A-3. ウェブアプリとして公開する

1. 右上の青い「**デプロイ**」→「**新しいデプロイ**」
2. 左の歯車マーク →「**ウェブアプリ**」を選ぶ
3. 設定を2か所だけ確認：
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員** ←ここ大事！
4. 「デプロイ」を押す
5. 表示された「**ウェブアプリのURL**」（https://script.google.com/macros/s/...で始まる長いURL）をコピーしておく

## ステップB: サイトにURLを貼る（約5分）

`js/reserve.js` を開くと、上のほうにこう書いてあります：

```js
const RESERVE_ENDPOINT = '';
```

この `''` の間に、さっきコピーしたURLを貼ります：

```js
const RESERVE_ENDPOINT = 'https://script.google.com/macros/s/あなたのURL/exec';
```

保存して main に push（いつものデプロイ）すれば、**フォーム予約が動き始めます**🎉

> 💡 URLを貼るまでの間、サイトのフォーム欄には自動で
> 「準備中です。LINEからご予約ください」と表示されるので、
> 先にサイトだけ公開しても大丈夫です。

**動作テスト**: 自分で reserve.html から1件予約してみてください。
①自分のGmailに通知 ②カレンダーに【仮】イベント ③お客様用アドレスに自動返信、の3つが届けば完璧です。

---

## ステップC: LINE通知をつける（任意・あとまわしOK）

**LINE予約ボット（rokkonline）で使っている「六根清浄 管理」Botをそのまま使い回せます。**
新しくBotを作る必要はありません。

1. rokkonline リポジトリの `00_Config.js` を開く
2. そこにある2つの値をコピーして、GAS（予約受付）のコード上部 CONFIG に貼り付ける：
   - `ADMIN_BOT_TOKEN` の値 → `LINE_CHANNEL_ACCESS_TOKEN` へ
   - `ADMIN_USER_ID` の値 → `LINE_OWNER_USER_ID` へ

```js
LINE_CHANNEL_ACCESS_TOKEN: '（ADMIN_BOT_TOKEN の値）',
LINE_OWNER_USER_ID: '（ADMIN_USER_ID の値、Uで始まる）',
```

3. 関数プルダウンから「**testNotify**」を選んで実行 → 自分のLINE（管理Botのトーク）に通知が来たら成功！
4. 最後に**デプロイの更新**：「デプロイ」→「**デプロイを管理**」→ 鉛筆マーク → バージョン「**新バージョン**」→「デプロイ」
   （これをやらないとコードの変更が反映されません。今後コードを直したときも同じです）

> 💡 ゼロからBotを作る場合（参考）: LINE Developers コンソールで Messaging API チャネルを作成し、
> チャネルアクセストークン（長期）と「あなたのユーザーID」を上記に設定、BotのQRコードを友だち追加する。
> なお「LINE Notify」は2025年3月に終了しているため使えません。

## 日々の運用（プルダウンで選ぶだけ）

予約の通知が来たら、スプレッドシートの該当行の「**対応状況**」列のプルダウンから選ぶ：

| 選択肢 | 何が起きるか |
|--------|--------------|
| **確定** | 第一希望の日時で確定。オンラインなら確定案内メール（Meet URL・支払い先入り）が**自動送信** |
| **確定2** | 第二希望の日時で確定（あとは同じ） |
| **別日提案** | 「ご希望の日時は難しい」＋**今ご案内できる空き日時リスト**入りのメールを自動送信。お客様は**メールに返信するだけ**（フォーム再入力は不要） |
| **お断り** | 丁寧なお断りメールを自動送信 |
| 保留／対応済み／案内済み | 何も送信されない（リマインドが止まるだけの手動運用向け） |

- **オンライン予約**: 「確定」で自動送信され、対応状況が「案内済み」に変わります。LINEにも完了通知
- **対面予約**: 「確定」で**Gmailに下書き**ができます。【★待ち合わせ場所をここに記入★】を埋めて送信 → 対応状況を「案内済み」に変更
- **別日提案の後**: お客様から返信が来たら、シートの「**第一希望**」をその日時に書き換えて「**確定**」を選ぶ → いつもの確定案内が自動送信されます
- 送信に失敗すると対応状況が「送信エラー（要手動対応）」になり、LINEとメールで知らせが来ます

何も選ばずに3時間経つと、LINEへ「未対応の予約があります」と再通知が来ます（見逃し防止）。

カレンダーの【仮】イベントは、確定で【確定】に自動リネーム、別日提案・お断りで自動削除されます。確定後の正式な開始時刻は手で直してください。

## 自動でやってくれること（操作不要）

| 機能 | 内容 |
|------|------|
| **前日リマインド** | 毎日17時ごろ、**翌日の確定済み予約**のお客様にリマインドメールを自動送信（オンラインはMeet URL入り）。送った件数はLINEにも届く |
| **送信忘れチェック** | 対面予約で「下書き作成済」のまま（=確定メールを送り忘れている）翌日予約があると、LINEで警告が来る |
| **月次レポート** | 毎月1日の朝、先月の受付件数・確定数・お断り数のまとめがLINEに届く |
| **リピーター表示** | 同じメールアドレスで過去に予約した方からの新規予約は、LINE通知の先頭に「🔁 リピーター（◯回目・前回◯月）」と表示される |

- 前日リマインドは「対応状況」が「**案内済み**」の行だけに送られます（確定処理をすると自動でこの状態になります）
- シートに「確定日時」「前日リマインド」列が増えていますが、**どちらも自動記入なので触らなくてOK**です
- お客様側にも、予約完了画面に「📅 希望日時をカレンダーに追加」ボタンが出ます（お客様の忘れ防止用。こちらの操作は不要）

## こまったときは

| 症状 | 確認すること |
|------|--------------|
| フォームが「準備中」のまま | ステップBのURL貼り付け＆pushができているか |
| 送信するとエラーになる | A-3で「アクセスできるユーザー: 全員」になっているか |
| LINE通知が来ない | Botを友だち追加したか／testNotifyで届くか／デプロイ更新をしたか |
| お客様にメールが届かない | 迷惑メールフォルダ。Gmailの無料アカウントは1日約100通まで送信可（予約用途なら十分） |
| 記録シートはどこ？ | 「【設定完了】」メールにURLが書いてあります（Googleドライブにもあります） |
| 「確定」と書いても何も起きない | コード更新後に setup() を再実行したか（トリガー登録）／GASの CONFIG に MEET_URL・支払い情報を記入したか／デプロイ更新をしたか |

## コード更新時にやること（毎回同じ3ステップ）

1. 最新の `reservation.gs` を全部コピーして GAS に貼り直し、CONFIG の `LINE_CHANNEL_ACCESS_TOKEN`・`LINE_OWNER_USER_ID`・`MEET_URL`・`PAY_PAYPAY_ID`・`PAY_BANK_TEXT` を記入し直す（実値はリポジトリに書かない）
2. **setup() をもう一度実行**する（新しいトリガーが自動登録される。新しい権限の承認が出たら許可）
3. 「デプロイ」→「デプロイを管理」→ 鉛筆 → 新バージョンでデプロイ更新
