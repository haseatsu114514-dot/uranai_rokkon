# ターゲットペルソナ

## 全体像

メインターゲットは **20〜35歳の女性**。恋愛の悩みが入口だが、仕事・人間関係にも展開できる。

共通心理: 「友達に相談しても"考えすぎ""次行きな"で終わる。本当にわかってくれる人に聞きたい。」

---

## ペルソナ① 片想い中の女性（最重要ターゲット）

| 項目 | 内容 |
|------|------|
| 年齢 | 22〜30歳 |
| 職業 | 会社員・事務職・販売職 |
| 状況 | 職場や友人関係で気になる人がいる。脈ありか脈なしかわからない |
| 悩み | 「あの人は私のことどう思ってる？」「このまま待ってていいの？」 |
| 行動 | Xやインスタで「片想い」「脈あり サイン」を検索。占いに頼ったことは1〜2回 |
| 心理 | 友達に相談しても「告れば？」で終わる。もっと具体的なアドバイスが欲しい |
| 支払い意欲 | 中（¥3,000〜8,000なら出せる） |

### 刺さるメッセージ
- 「あの人の本音、知りたくない？」
- 「"脈なし"って本当にそう？四柱推命で読んだら意外な答えが出た」
- 「待つべきか、動くべきか。"いつ"がわかれば不安は消える」

### 最適商品
- **入口:** 30分鑑定（¥3,300）or「あの人のトリセツ」レポート（¥8,000）
- **アップセル:** 45分鑑定、運勢ナビ

## ペルソナから逆算したブランドポジション

```
「友達に話しても"考えすぎ"で終わる悩みを、
四柱推命で具体的に読み解いて、
"次にどうすればいいか"まで教えてくれる人」
```

→ 「当てる占い師」ではなく **「解決する占い師」** がポジション。
→ 「あの人のトリセツ」はまさにこのポジションを体現した商品名。
