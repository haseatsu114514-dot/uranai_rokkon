# リスクシナリオと対策

最悪ケースでも「鑑定だけで月¥48,000〜60,000」を確保できる設計にしておく。

---

## リスク①: Xが伸びない（6ヶ月でフォロワー300人未満）

**影響:** サイトへの流入が増えず、レポート販売・新規鑑定予約が停滞

**対策:**
- ココナラ・メルカリ等の外部PF経由の集客を強化
- Googleビジネスプロフィール + SEO記事で検索流入を狙う
- X運用方針を見直し（型・トーン・頻度を変えてテスト）
- Instagramに注力を切り替え（Xより女性向き）
- 最悪でも鑑定月8件（自サイト+ココナラ）で¥48,000は維持可能

## リスク②: レポートが売れない（月0〜1件が3ヶ月続く）

**影響:** STAGE 2の¥100,000達成が困難

**対策:**
- モニター価格を延長（¥3,000〜5,000）で実績・レビューを積む
- 鑑定のアップセル（鑑定後に「レポートもあります」と案内）に注力
- サンプルページ公開: レポートの一部（2〜3ページ）をサイトで公開
- 「初回限定¥5,000」の常設割引を検討
- 代替案: 鑑定件数を増やす（月10件×¥6,000=¥60,000）

## リスク③: note記事が売れない（月¥2,000未満が続く）

**影響:** ストック型収益が育たず鑑定依存が続く

**対策:**
- 有料部分の「ここから先が読みたい」設計を改善
- noteをブランディング・集客ツールとして位置づけ直す
- 有料記事の価格を¥300〜500に下げてテスト
- X長文ポストで同等のコンテンツを出し、集客に振り切る

## リスク④: 鑑定疲れ・モチベーション低下

**影響:** 活動自体が止まる（個人事業最大のリスク）

**対策:**
- 1日2件・週3日の上限を厳守
- 「作業日」と「鑑定日」を曜日で分ける
- 月に1週間の「充電週」を設定
- 売上が¥50,000を安定して超えたら自分へのご褒美を設定
