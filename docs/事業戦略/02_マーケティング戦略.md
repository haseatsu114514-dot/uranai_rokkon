## X（Twitter）戦略

アカウント名: **占い師あつき｜あの人のトリセツ**

### サムネ付き長文ポスト（最優先フォーマット）

Xで今最も伸びている形式。サムネ画像で目を止め、タップで長文が展開される。

**コンテンツの型:**
1. 恋愛あるある型: サムネ「既読スルーする男の本音、全部書く」→ 心理分析 → トリセツへ誘導
2. 有名人分析型: サムネ「○○と○○の相性を四柱推命で見た」→ 命式解説
3. 毒舌本音型: サムネ「占い師が絶対言わないこと」→ 業界裏話
4. 教育型: サムネ「四柱推命で"モテ期"は本当にわかる」→ noteへ誘導

**サムネ画像:**
- Canvaで統一テンプレ（和風×明朝体）
- 文字は大きく1〜2行。「目を止める」が目的
- 投稿頻度: 週2〜3本

**導線:** サムネ長文ポスト → プロフィール → 固定ツイート → サイト(about.html) → LINE → 購入/予約

### 日常投稿ルーティン

- 毎日: 朝の一言（今日の運勢ミニ or 豆知識）
- 週2〜3回: サムネ長文ポスト（上記の型）
- 週1回: note記事の告知
- 月1回: フォロワー参加型企画（RT抽選ミニ鑑定等）

### 最初の30日プラン

**Week 1:**
- Canvaでサムネテンプレ3種作成（恋愛あるある/有名人分析/毒舌本音）
- テスト投稿2本
- 投稿時間テスト: 朝7時 / 昼12時 / 夜21時

**Week 2-3:**
- 週3本ペースでサムネ長文ポスト
- 毎日の一言投稿も継続
- 反応の良い型を特定（いいね・リプ・プロフクリック率で判定）

**Week 4:**
- 月間データ振り返り
- 反応の良い型に集中する方針を決定
- 翌月コンテンツカレンダー作成

**30日後の判断基準:**
- フォロワー+50人以上: 好調。継続
- フォロワー+20〜50人: コンテンツ改善
- フォロワー+20人未満: 型・トーン・時間帯を大幅見直し

## Threads（スレッズ）戦略

### メリット

- Instagramと連動 → フォロワー引き継ぎ
- Xより女性ユーザー比率が高い → ターゲット層とドンピシャ
- 競合が少ない → 先行者利益
- アルゴリズムがフォロワー数に依存しにくい → 0からでもバズれる
- 炎上リスク低い

### 運用方針

- Xの投稿をそのまま転載（追加コストゼロ）
- Xでは尖った投稿、Threadsではやや共感寄りのトーンで棲み分け
- プロフィールにサイトURL設置
- Instagram連携: Threadsで文字 → Instagramでビジュアル

## Instagram戦略

Threadsとの連携を前提にした、ビジュアル特化のブランディング＋集客チャネル。

### なぜInstagramか

- **女性ユーザー比率60%以上** → 恋愛占いのメインターゲット
- **ビジュアルで「世界観」を伝えられる** → 六根清浄の和風ブランディングが映える
- **Threads・Reelsとの一体運用**で1つの素材を3つの場所に展開
- **保存・シェア文化**が根付いている → 「占いコンテンツ」は保存されやすい
- **ハイライト機能**で「鑑定の流れ」「お客様の声」を常設展示できる

### アカウント設計

- **アカウント名:** 占い師あつき｜あの人のトリセツ（Xと統一）
- **プロフィール写真:** 和風・品のあるアイコン（サイトと統一）
- **bio:** 四柱推命鑑定士｜1,500件以上の実績｜あの人の本音、読み解きます。▼ 鑑定・レポートはこちら
- **リンク:** about.html（Linktreeは使わず直リンクでシンプルに）
- **ハイライト:** 「鑑定の流れ」「お客様の声」「四柱推命とは」「よくある質問」

### フィード投稿の型

#### ① カルーセル（スワイプ型）← メインコンテンツ

**最も保存・シェアされやすいフォーマット。** 1投稿で5〜10枚のスライドを使い、ミニ講座形式で解説。

テンプレ例:
- 「既読スルーする男の心理 5選」（1枚目=タイトル、2-6枚=各特徴、7枚=まとめ+CTA）
- 「四柱推命でわかる"あの人のタイプ"」（日干別の性格解説）
- 「片想いが実る人・実らない人の違い」
- 「復縁できる相性・できない相性」
- 「占い師が教える"いい男"の見分け方」

**デザインルール:**
- Canvaテンプレ: 和風背景（墨色 or 深紫 × 金のアクセント）
- フォント: 明朝体メイン（サイトと統一）
- 1枚目（表紙）で引きを作る → 2枚目以降はシンプルに読ませる
- 最後のスライドに必ずCTA:「もっと深く知りたい方 → プロフィールのリンクから」

#### ② シングル画像（名言・格言系）

和風デザインの1枚画像に短いメッセージ。

例:
- 「"脈なし"って本当にそう？」
- 「既読スルーの裏側には、いつも理由がある」
- 「あの人の"冷たさ"は、実は"不器用さ"かもしれない」

→ 保存数を狙う。タイムラインで目を引き、プロフィールへ誘導。

#### ③ Reels（ショート動画）

TikTok/Shortsと同じ素材を転用。追加コストゼロ。

- 「○○な彼のトリセツ」シリーズ
- 有名人の相性分析（60秒版）
- 占い師のぶっちゃけトーク

**Reels → フィードへの回遊を狙う。** Reelsで新規リーチ → プロフィール訪問 → カルーセルで教育 → サイトへ。

### ストーリーズ運用

- **毎日1〜3投稿**（タイムラインより気軽。「今日の一言」「裏話」「日常」）
- **質問箱:** 「恋愛の悩み、匿名で聞いてみて」→ 回答で鑑定力アピール
- **アンケート:** 「既読スルーされたらどうする？① 待つ ② もう1通送る ③ 諦める」→ エンゲージメント向上
- **カウントダウン:** 「モニター募集開始まであと○日」等のイベント告知
- **ハイライトに保存:** 重要なストーリーは「鑑定の流れ」「お客様の声」等のカテゴリに常設

### ハッシュタグ戦略

**メインタグ（毎回使用・5〜8個）:**
`#占い` `#四柱推命` `#恋愛占い` `#片想い` `#相性占い` `#あの人の本音` `#占い師あつき`

**サブタグ（内容に応じて3〜5個追加）:**
- 恋愛系: `#既読スルー` `#復縁` `#マッチングアプリ` `#恋愛相談`
- 開運系: `#運勢` `#開運` `#2026年運勢`
- 一般系: `#自分磨き` `#メンタルケア` `#大人女子`

→ 合計10〜15個。多すぎるとスパム判定されるので厳選。

### Instagram × Threads × X の連携運用

| 素材 | X | Threads | Instagram |
|------|---|---------|-----------|
| サムネ長文ポスト | ◎メイン | 転載 | - |
| カルーセル | - | - | ◎メイン |
| 名言画像 | 転載 | 転載 | ◎メイン |
| Reels/ショート動画 | - | - | ◎（+TikTok/Shorts同時投稿） |
| 毎日の一言 | ◎メイン | 転載 | ストーリーズ |
| 質問箱・アンケート | - | - | ストーリーズ |

→ **1つの素材を最大3プラットフォームに展開。** 追加工数はほぼゼロ。

### 投稿頻度（目安）

- フィード: 週3〜4投稿（カルーセル2 + 名言画像1 + Reels1）
- ストーリーズ: 毎日1〜3本
- Reels: 週1〜2本（TikTok素材の転用）

### 最初の30日プラン

**Week 1:**
- アカウント設計（bio・プロフィール写真・ハイライトカバー作成）
- Canvaでカルーセルテンプレ作成（表紙+本文+CTA）
- テスト投稿: カルーセル1本 + 名言画像1本

**Week 2-3:**
- 週3投稿ペースで運用開始
- ストーリーズ毎日投稿開始
- Reels 1本テスト（X長文ポストのダイジェスト版）
- ハッシュタグの反応を見て調整

**Week 4:**
- 保存数・リーチ数・プロフィール訪問数を確認
- カルーセルと名言画像、どちらが反応良いか判断
- 翌月は反応の良い型に集中

## note戦略

### 3つの役割
1. ブランディング:「四柱推命の専門家」としての認知
2. 集客: SNS・検索から鑑定やLINEにつなぐ
3. 収益: 有料記事で直接マネタイズ

### 有料記事の価格帯

| タイプ | 価格 | 内容 |
|--------|------|------|
| ライト | ¥300〜500 | 1,000〜2,000字 |
| スタンダード | ¥800〜1,500 | 3,000〜5,000字、命式分析込み |
| プレミアム | ¥2,000〜3,000 | 5,000字以上、図解付き |

### 時事ネタ × 四柱推命

「有名人・ニュースを四柱推命で読み解く」= バズりやすく専門性もアピールできる最強コンテンツ。

- 前半（無料）で引きを作り、後半（有料）で詳細分析
- ニュースが出たら24〜48時間以内にスピード公開
- 芸能人の写真は使わず、図解やチャートで視覚化

## DRMファネル戦略

SNSからの流入を「見込み客 → 購入者 → リピーター」に育てる仕組み。

### ステップ1: 無料コンテンツで「教育」する
- X長文ポストやnote無料記事で「四柱推命でここまでわかる」を見せる
- 具体例を出すほど「自分もやってほしい」という欲求が生まれる

### ステップ2: LINE登録でリスト化
- 登録特典:「あなたの"恋愛タイプ"を無料診断」
- 自動応答で簡易結果 →「もっと詳しくは"あの人のトリセツ"がおすすめ」
- 週1回の教育配信

### ステップ3: 段階的オファー
- まず¥8,000の「あの人のトリセツ」レポートを提案（ハードル低い）
- レポート購入者に「鑑定もあります」とアップセル
- 鑑定後に「運勢ナビ」「完全鑑定書」をクロスセル

### ステップ4: リピーター化
- 季節ごとの運勢ナビ案内（3ヶ月ごとの自然なリピート）
- 紹介割引:「友達と一緒にトリセツを頼むと¥500OFF」
- 記念日リマインド:「前回の鑑定から半年。最近いかがですか？」

## 集客導線

```
認知 → 興味・信頼構築 → 予約・購入 → ファン化・リピート
```

### チャネル別フロー

- **X/Threads** → サイト（about.html）→ LINE → 鑑定予約 or レポート注文(BASE)
- **Instagram** → プロフィールリンク → サイト → LINE → 購入
- **TikTok/Shorts** → プロフィール → note or サイト → LINE
- **note** → 有料記事購入 or サイト → 鑑定予約

### コンバージョンファネル（想定転換率）

```
Xインプレッション 10,000
  → プロフクリック 200（2%）
    → サイト訪問 100（50%）
      → LINE登録 10（10%）
        → 購入 1（10%）
```

→ レポート月5件に必要なインプレッション: **約50,000/月**
→ Xフォロワー1,000人で平均インプレッション50,000〜100,000は現実的

### ファネル改善のレバー

- プロフクリック率（2→4%）: サムネのフック改善
- サイト→LINE登録率（10→20%）: CTA強化、LINE登録特典
- LINE→購入率（10→20%）: 教育配信の質向上

### 計測方法

- Xインプレッション: Xアナリティクス（無料）
- サイト訪問: **Googleアナリティクス（要設置 ← 最優先）**
- LINE登録: LINE Official Account管理画面
- 購入: BASE注文管理

## 追加マーケティング施策

### LINE登録特典の設計

現状、LINE登録するインセンティブが弱い。登録特典を用意するだけで登録率が2〜3倍になる。

**特典案（制作コスト低い順）:**
1. 「あなたの恋愛タイプ診断」（生年月日→日干から簡易診断。テンプレ化で対応5分）
2. 「今月の恋愛運ミニレポート」（毎月更新の1ページPDF）
3. 「初回鑑定¥500OFF」クーポン
4. 「相性の見方ミニ講座」（3日間のステップ配信）

→ おすすめは①。低コストで「もっと知りたい」を引き出せる。

### 口コミ・紹介プログラム

占いは口コミが最強の集客チャネル。仕組み化する。

- 鑑定後に「もしよかったら友達にも教えてあげてください」とLINEで伝える
- 紹介カード（デジタル）: 紹介者に次回¥500OFF、被紹介者に初回¥500OFF
- 「友達と一緒にトリセツを頼むとそれぞれ¥500OFF」
- 紹介が発生したらXで「ご紹介ありがとうございます」と（匿名で）発信 → 社会的証明

### 季節イベント連動

占いと季節イベントは相性抜群。事前にコンテンツカレンダーを組んでおく。

| 時期 | イベント | コンテンツ例 |
|------|----------|-------------|
| 2月 | バレンタイン | 「あの人にチョコ渡すべき？四柱推命で判定」 |
| 3月 | 新生活 | 「4月からの運勢ナビ」販促 |
| 5月 | GW | 「連休に告白するべき？最適タイミング診断」 |
| 7月 | 七夕 | 「運命の人の特徴を四柱推命で見る」 |
| 10月 | ハロウィン | 「あの人の"裏の顔"を暴く」 |
| 12月 | 年末年始 | 「来年の運勢ナビ」販促、12ヶ月レポート |

### SEOブログ記事（サイト内）

サイトのblogディレクトリを活用。検索経由の長期的な集客チャネル。

**狙うキーワード:**
- 「四柱推命 相性」「四柱推命 片想い」「既読スルー 男性心理 占い」
- 「名古屋 占い おすすめ」「オンライン占い 当たる」

→ 1記事2,000〜3,000字。月2本ペース。即効性はないが6ヶ月後から流入が増え始める。

### コラボ企画

他の占い師・スピリチュアル系アカウントとのコラボ。

- Instagram Live: 「○○先生と相性トーク」（互いのフォロワーに露出）
- X相互紹介: 占術の違う占い師と「タロット×四柱推命コラボ鑑定」企画

→ フォロワー500人を超えたあたりからコラボ企画を打診していく。
