# 名古屋ナイトウォーク — NAGOYA NIGHT WALK 🌃

初代ペルソナのダンジョン探索／ダンガンロンパの探索パートのような
**一人称・4方向視点**で、名古屋（栄）の夜の街を歩き回る実験的な 3D デモ。

> ⚠️ 本サイト（占い処 六根清浄）の本体とは無関係の **実験用** ページです。
> `experiments/` 配下に隔離してあり、サイトの導線からは一切リンクしていません。

## 遊び方

`experiments/nagoya-night-walk/index.html` をブラウザで開くだけ。
（ビルド不要。Three.js は CDN から読み込みます＝ネット接続が必要）

ローカル確認：

```bash
cd experiments/nagoya-night-walk
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 操作（ペルソナ／ダンガンロンパ風）

| 入力 | 動作 |
|------|------|
| `W` / `S`（↑/↓） | 向いている方向へ 前進・後退 |
| `A` / `D`（←/→） | **90°ずつ振り向く**（向ける方向は東西南北の4方向） |
| `SHIFT` | 走る |
| `SPACE` | 見上げる |
| `ESC` | 一時停止（クリックで再開） |
| スマホ | 左下スティック上下＝移動／左右＝振り向き |

## 見どころ

- 名古屋テレビ塔（赤い鉄塔）と オアシス21 風のガラスリングをランドマーク配置
- 手続き的に生成したビル群＋日本語ネオン看板（味噌・手羽先・喫茶 …）
- 濡れたアスファルトの反射（Reflector）＋ UnrealBloom でネオンが滲む夜景
- 走る車のテール／ヘッドライト、街路灯、自販機、赤提灯、霧雨、星と月

## 技術

- Three.js r160（ESM / importmap, CDN: unpkg）
- ポストプロセス: EffectComposer + UnrealBloomPass + OutputPass
- 反射: `Reflector`、トーンマッピング: ACESFilmic
- 単一 HTML ファイル完結（外部アセットなし／テクスチャは Canvas で生成）

## パフォーマンスメモ

ネオンの発光は基本的に **emissive マテリアル + Bloom + 反射** で表現し、
動的ライトは月光＋ランドマーク2灯のみに抑えて軽量化している。
重い場合はブラウザのハードウェアアクセラレーションを有効に。
